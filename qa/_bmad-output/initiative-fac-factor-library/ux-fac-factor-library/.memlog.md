- (decision) One persona, Priya Nair, sustainability lead at a small UK haulage firm. Web app, desktop first, usable on a phone.
- (decision) Look: navy #0F3567, green #70AC46, blue #3B90E5, amber #F8B702, Poppins with system fallback, cards with 8px radius. Colour never carries meaning alone.
- (decision) Every figure shows a status. The workshop only shows Indicative. The web app never calculates and never re-sorts.
- (decision) Three screens: Factor library, Record activity, Footprint summary, reached by three tabs and a URL hash.
