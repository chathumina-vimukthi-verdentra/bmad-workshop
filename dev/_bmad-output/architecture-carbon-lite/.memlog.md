- (direction) Source: master PRD _bmad-output/prd-carbon-lite/prd-carbon-lite.md. Derives from the real Carbon Hub master spine in simplified form.
- (decision) [ADOPTED] Paradigm: modular monolith. One API process, one web app, three modules (factors, activities, footprint) each with routes, service, repository, types.
- (decision) [ADOPTED] AD-1: one-way dependency footprint -> activities -> factors, no cycles. Prevents circular imports and hidden coupling.
- (decision) [ADOPTED] AD-2: one writer per aggregate. Factors owned by factors, activities by activities, footprint owns nothing durable.
- (decision) [ADOPTED] AD-3: factors immutable and versioned. A new value is a new id.
- (decision) [ADOPTED] AD-4: decimal strings on the wire and in storage, decimal.js for arithmetic, rounding only in the footprint calculation. Binds CLT.NFR-1.
- (decision) [ADOPTED] AD-5: every figure carries Verified or Indicative. Only Indicative is produced.
- (decision) [ADOPTED] AD-6: an activity pins the factor id at creation. Calculation never looks up latest. Binds CLT.NFR-2.
- (decision) [ADOPTED] AD-7: /api/v1 prefix, JSON, problem+json errors, lists as {count, items}. Binds CLT.NFR-3.
- (decision) [ADOPTED] AD-8: module layout apps/api/src/modules/<slug>/ with four files. Modules talk only through service interfaces.
- (decision) [ADOPTED] AD-9: Node.js 24 LTS, TypeScript, Fastify 5, Vitest, decimal.js, React 19, Vite, npm workspaces. Production Carbon Hub is C# on .NET with React; the sample stack differs on purpose.
- (decision) [ADOPTED] AD-10: API tests with fastify.inject, one file per endpoint group, every acceptance criterion has a passing test. Binds CLT.NFR-4.
